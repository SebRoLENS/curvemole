# CurveMole 1.1.0 — retrospective stable notes

These notes summarize the changes shipped with the published 1.1.0 stable
release on 28 October 2026. They were reconstructed from the actual commits
between Git tags v1.0.1 and v1.1.0 because the 1.1.0 section of the original
stable CHANGELOG.md was left empty. This file is a manually curated historical
record for the website, not an unreleased feature list.

### Added

- **Stable and Beta update channels.** Choose the update channel in Help. Returning to Stable never silently downgrades an installed beta.
- **Single-instance desktop file opening.** Files opened from the operating system are forwarded to one CurveMole window, with a batch-import dialog for multiple inputs.
- **Expanded Calculator and point-based model editing.** Guided operations, selected-spectra targeting, RAW-data restoration and interactive add/move/delete controls for function initialization.
- **Function setup before insertion.** Configure initial parameter values, bounds and supported point-based options before placing a new function.
- **Keyboard command shortcuts.** Access more workspace commands with context-sensitive keys while preserving normal typing in text fields.

### Changed

- **Faster startup and lighter interaction.** Load optional scientific backends and enabled plugins on demand or after first paint; reuse plot elements when updating Overlay and Waterfall.
- **More predictable fitting and rendering.** Separate fit and rendering responsibilities, improve progress/result handling, and add regression coverage for scientific state changes.

### Fixed

- **Point editor and Undo consistency.** Retain peak shapes during edits, reapply edited background subtractions as reversible operations, and correctly restore related parameters and results.
- **Model, global-fit and uncertainty integrity.** Invalidate dependent results after linked-model edits, keep covariance blocks and numerical data consistent, and preserve workflow identities.
- **More reliable shortcuts and file opening.** Correct assignment conflicts and stale saved keys; prevent a Windows file-open acknowledgement race.
